# J2J: Jabber-to-Jabber Transport

## Назначение

**J2J** — это XMPP-транспорт (компонент, XEP-0114), который подключает
**гостевую учётную запись** пользователя на удалённом сервере к его
**хост-аккаунту** и транслирует контакты гостя в ростер хоста. Общаться с
ними можно так же, как с обычными контактами основного ростера.

Проще говоря: мост «мой основной Jabber-аккаунт ↔ мой/чужой гостевой аккаунт».

## Возможности

- XEP-0114 компонент (`jabber:component:accept`), работающий от имени
  подключённых пользователей.
- **Виртуальные JID**: контакты гостя показываются в ростере хоста
  (экранирование `@`→`%`; поддержка legacy-экранирования XEP-0106).
- **Импорт ростера** несколькими способами: выключен / через подписки /
  через XEP-0144 (roster item exchange) / авто-выбор.
- **Message Carbons** (XEP-0280): сообщения, отправленные с других клиентов
  гостевого аккаунта, зеркалируются в чаты на стороне хоста.
- **vCard**: просмотр визиток виртуальных JID и репликация визитки хоста в
  гостя.
- Gateway (jabber:iq:gateway), disco, stats, браузер сервисов.
- **Автоответчик** и настройки пересылки (уведомления о печати/активности/
  доставке), режим «только контакты гостевого ростера».
- **Управление транспортом**: через чат-меню и ad-hoc команды; админ-команды
  (язык по умолчанию, режим импорта, stop/restart, объявления).
- **Локализация** интерфейса: русский, английский, украинский.
- **Шифрование** паролей гостевых аккаунтов в базе (master-пароль, Fernet).
- **Защита от закольцовки**: нельзя подключить собственную учётную запись.
- Устойчивость к повреждённым станзам и «мёртвым» TCP-соединениям.

## Системные требования

- **Python 3.11+** и `pip`.
- Зависимости (устанавливаются из `requirements.txt`):
  `slixmpp==1.10.0`, `aiodns>=3.2.0`, `pyasn1>=0.6.1`,
  `pyasn1-modules>=0.4.1`, `cryptography>=3.4`.
- **XMPP-сервер** с поддержкой компонентов (XEP-0114) — для подключения
  транспорта как компонента.
- **SQLite** (встроен в Python) — отдельный сервер БД не нужен.
- ОС: POSIX для демонизации (`-b`); сам компонент работает и без неё.

## Установка

```sh
git clone <url-репозитория> j2j
cd j2j
python3 -m venv .venv          # рекомендуется
source .venv/bin/activate
pip install -r requirements.txt
```

## Конфигурация

Скопируйте шаблон в один из путей, которые ищет транспорт в порядке
приоритета: `j2j.conf` (текущий каталог), `~/.j2j/j2j.conf`,
`/etc/j2j/j2j.conf`.

```sh
cp j2j.conf.example j2j.conf
```

Ключевые секции:

- `[component]` — адрес подключения транспорта к серверу: `JID`,
  `Host`, `Port`, `Password` (общий секрет XEP-0114); `Send_probes`.
- `[general]` — язык по умолчанию (`default_language`), режим импорта
  ростера (`import_mode`: off/subscribe/rosterx/auto) и имя группы для
  импортируемых контактов (`roster_group_name`).
- `[database]` — путь к файлу БД (`Name`) и опциональный `master_password`
  для шифрования паролей гостей. **Если задан master_password, не разглашайте
  и не теряйте его** — он является ключом шифрования.
- `[admins]` — список администраторов (`List`) и уведомления о регистрациях.
- `[process]` — путь к PID-файлу.
- `[debug]` — логирование: файл, уровень, дампы станз.

## Запуск

```sh
python3 main.py -c /path/to/j2j.conf
```

Опции CLI:

- `-c FILE, --config FILE` — кастомный путь к конфигу;
- `-b, --background` — запустить как демон (daemonize).

Остановка — через `SIGINT`/`SIGTERM` (или ad-hoc команду admin). PID-файл
удаляется автоматически.

На сервере зарегистрируйте компонент с тем же JID и секретом, что в
`[component]`, и укажите порт компонента.

## Краткое руководство по использованию

### Регистрация

Подключите транспорт как контакт (JID транспорта). Зарегистрируйте
гостевую учётную запись одним из способов:

- **Форма регистрации** (`jabber:iq:register`) — вызывается клиентом;
- **ad-hoc команда «register»** — через меню команд транспорта;
- **чат** — команда `reg` в диалоге с контактным JID транспорта.

Поля формы: **JID** гостя (`user@server`), **пароль**, **домен/порт**
(если отличаются), **режим импорта ростера**, **группа** для импортированных
контактов, **язык** интерфейса.

> Нельзя зарегистрировать аккаунт, совпадающий с вашим собственным
> (защита от закольцовки).

### После подключения

- Контакты гостя появляются в основном ростере под виртуальными JID —
  общайтесь с ними как с обычными контактами.
- Статус транспорта показывает подключённую гостевую учётную запись.

### Чат-команды (`в диалоге с транспортом`)

- `reg` — регистрация / `mod` — изменить аккаунт;
- `lang` — язык интерфейса;
- `on` / `off` — включить/выключить транспорт для своего аккаунта;
- `del` — удалить аккаунт (вместе с виртуальными контактами);
- `vcard` — скопировать визитку хоста в гостя;
- `arepl` — автоответчик;
- `trans` — настройки пересылки и синхронизации;
- `help` или `?` — справка.

### Ad-hoc команды

- `register`, `options` (настройки аккаунта), `stat` (статистика),
  `replicate_vCard`, `delete_account`.
- `admin` — только для администраторов: язык по умолчанию, режим импорта,
  группа, остановка/перезапуск транспорта, объявления пользователям.
